How it works

One card, held for the whole day

The card is chosen at random from a sample deck of twelve Major Arcana cards, then remembered in this browser so the same card stays with you until tomorrow. Read it slowly, and notice whether it still feels relevant at the end of the day.

  • The draw is free and needs no account.
  • You can share it with the Share Reading button.
  • Each card includes a question to reflect on and an affirmation to keep.

About the daily limit on this demo

This website is currently a static, front-end prototype. The once-a-day limit is stored in your browser using localStorage, which means:

  • Clearing your browser data or using a private window resets it.
  • It cannot be enforced reliably, and it is not tied to an account.
  • The "Draw again (demo reset)" button exists so you can test the feature.

On a live site with user accounts, a genuine one-card-per-day limit would be enforced on the server, where it can actually be trusted.

The deck

Twelve Major Arcana cards, each with its own reading

This demo ships with twelve fully written cards. Each one has a general meaning, a reading for love questions, a reading for career questions, a reflection question and an affirmation.

Card artwork on this site is original vector artwork created for this project. If you would rather use a published deck, make sure you hold the licence for the artwork before swapping it in.
